API guide

1. Run the server

Start it from Settings, or run Novela.Core serve --port 4477. The server prints the address it listens on.

2. Endpoints

GET /api/health checks the server. POST /api/obfuscate takes {source, options, seed} and returns {success, output, stats, logs, error}. Bodies are JSON in UTF-8.

3. Example

curl -X POST http://127.0.0.1:4477/api/obfuscate -H "Content-Type: application/json" -d "{\"source\":\"print(1)\",\"seed\":7}"

4. Token

Set a token on the server and send it as X-Novela-Token. Requests without it get 401.

5. Hosting

Host it anywhere you like: your own VPS, a home PC, or just keep the local server on this machine. For remote use, bind --host 0.0.0.0 and put it behind HTTPS.
